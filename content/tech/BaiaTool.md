# BaiaTool (interno)

## Resumo

Dispositivo de monitoramento e agendamento de baias rotativas.

## Features

- Interface visual para identificação do estado atual da baia
  - Em uso, Reservada, Livre
  - Fita LED circular com cores diferentes para cada estado
- Interação através do uso de crachá e APP
- Rastreio de colaboradores que utilizaram a baia
  - Para segurança e controle interno
  - Para encontrar onde um colaborador pode ser encontrado

## Requisitos

### IN

- Lista de ID dos colaboradores
- Informações de agendamento

### OUT

- Informação da baia (estado e ações que aconteceram)
